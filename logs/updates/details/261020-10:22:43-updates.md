# 261020-10:22:43 — Simplify and share semantic region definitions with exact coverage preservation

## Motivation
Reduce fragmented task/path region definitions and share equivalent regions
across experts while preserving local accuracy and avoiding coverage regressions.

## Changes
- `critical/core/calibration/shared_regions_v27.py`: canonical evidence conjunctions,
  cross-scope/expert pooling, exact absorption and complementary-literal identities,
  bounded symbolic equivalence proofs, shared literal/task catalogs, support
  deduplication and per-task support counts; standalone replacement region gate.
- `run/calitree_shared_regions_v27.py`: offline build/replay and audit that verifies
  exact v26 routing/final-label equivalence, symbolic formulas and support counts.
- `tests/unit/calitree/test_shared_regions_v27.py`: nine tests covering Boolean
  identities, unsafe label/scope grouping, proof-budget failure, literal validation,
  local preservation, order invariance, artifact validation, cross-expert sharing
  without double-counting and exhaustive small-domain equivalence checks.
- `docs/calitree_shared_regions.md`, results/audit JSON, portable examples and
  `run/README.md`: interpretation, limitations and opt-in usage.

## Design decisions
Only provable Boolean identities are allowed, not empirical feature equivalences.
Canonical evidence definitions are independent of expert and task IDs, while
permitted structural task scopes and expert links remain explicit. The deployed
runtime retains the v24 consensus/rejection gate but does not hide or execute the
old v26 region bank. It never introduces a new verdict or weakens disagreement
handling. Pooled support deduplicates sources; per-task counts prevent pooled
support from hiding singleton task coverage.

The first expanded-condition draft reduced definition counts but increased
serialized size. Its output and source snapshots are preserved under
`logs/exps/261020-shared-regions-v27`. The final run uses a shared literal table
and is audited/sealed under `logs/exps/261020-shared-regions-v27-r1`.

## Follow-ups

cross-expert semantic generalization would require relaxing exact-equivalence
criteria in a separately measured experiment. Keep the current version opt-in;
it makes no unseen-image correctness or latency claim.
