# 261020-10:00:49 — Define semantic rule regions for mixed expert routing

## Motivation
Make semantic task coverage and evidence-backed decision coverage explicit so
inputs can be assigned to supported expert regions and otherwise use the regular
judge, while retaining local accuracy.

## Design decisions
A task signature only shortlists candidates. A final tree verdict additionally
requires its original evidence guards, semantic envelope, complete terminal path
and all old rejection checks. The full-bank gate remains a veto so narrowing the
shortlist cannot erase disagreement. This prototype does not claim fewer model
calls or tree executions and does not change default inference.

Regions are built on correct original local examples only. One example is enough
to retain a narrow task/path region, with that support count explicitly exposed;
the inherited broader evidence rule's repeated support is not misrepresented as
repeated support for every narrow region. No coverage probability is estimated.
Original case/source names are not runtime predicates. Trees and verdicts are not
refitted or changed. Regions must be rebuilt after future expert merges.
