## Motivation

The user requested GEPA and TextGrad modifications that can edit executable decision rules and a full twelve-case comparison against the existing custom local optimizer. The authorized budget was 1,800 calls and 2,304,000 completion tokens.

## Design decisions

Use the actual library algorithms rather than similarly named custom heuristics. Native TextGrad operates on one graph variable and GEPA reflects over the same executable genome. Both may edit structure, but preserve the original context and required provenance. Checker and audit calls exclude reference labels; optimizer feedback is case-local. Existing prompt-only adapters and custom optimizer behavior remain unchanged.

The comparison tests constrained integrations: native methods replace whole graphs whereas custom uses typed transactions. GEPA's single-case Pareto setting does not provide generalization evidence. Identical seed artifacts receive separate fresh seed draws per arm.

A post-run offline edge-case test found missing nested type validation in the new genome decoder. Hardened that parser without changing any live candidate or replaying model slots. All 106 saved candidate records pass the stricter validator. The live source snapshot remains frozen; current-code live resume intentionally rejects its old implementation hash. Read-only reporting/replay remains supported.
