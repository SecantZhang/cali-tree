## Design decisions
The mapping IF1=no, IF2/3=partial, IF4=yes is explicitly provisional and does not replace the
original 1–4 score with an asserted semantic gold label. Quality and overall preference do not
determine that class. The released training score is a single anonymous expert annotation;
pair appearances are not independent raters. No model calls or label adjudication ran.

Splits group decoded RGB source pixels, keeping all instructions/editors together. Current
parent trainers require one fitting row per source, so exports choose one output per eligible
source while preferring underrepresented reference classes within each partition, before any
model observations. Fitting class counts are 18 no / 18 partial / 19 yes; selection 5 / 4 / 4;
evaluation 4 / 4 / 5. These small, class-conscious cohorts are diagnostic samples, not population
prevalence or demonstrated accuracy.

Range extraction cannot verify an entire original parquet against its full LFS digest; no such
claim is made. Exact Range/Content-Range checks, pinned URLs, footer hashes, cached annotation
hashes and actual extracted asset hashes provide recorded provenance. Failed setup is resumable;
completed replay runs without network access. The source-overlap check is exact pixel matching,
not a certification of all perceptual duplicates, pretraining or historical exposure.
