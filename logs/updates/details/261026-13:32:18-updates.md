## Design decisions

Leaf budgets8/16/32/64/128, two feature views, three training target choices and
two weighting methods were declared before fitting. The primary is the32-leaf
balanced human-label/full-evidence tree. Fitting selects only an anchor weight
using the protected originals, never held labels. Failed local-retention arms
remain ineligible; no membership lookup or boosted fallback repairs them.

The best eligible model is64-leaf V144 hard-label distillation over full
primitive evidence:203/276 (73.6%),64.1% balanced accuracy. V112 remains227/276
(82.2%),67.9%; V144 remains226/276 (81.9%),71.1%. No8/16-leaf fit configuration
retains99 originals across all contexts. Thirty of sixty configurations qualify.

The primitive feature pool intentionally excludes teacher supports and
boost-dependent local review. This produces a true standalone tree but does
not equalize all evidence available to the full V112/V144 stack. The negative
result is not a proof that semantic compression is impossible.

Run r1 stopped at first artifact serialization because sklearn returned a numpy
integer leaf count. Explicit Python integer conversion fixed metadata; r1 is
preserved and the study completed in fresh r2. No neural/API calls occurred.
