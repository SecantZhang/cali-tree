## Design decisions

The mixed-judge gate keeps explicit semantic grade warrants and an actual
independent image judgment. A collateral objection does not erase legitimate
progress. A missing or uncertain fact does not by itself establish No. The
second rule also uses low normalized teacher support as a review cue, never
factual confidence. Source IDs, object names and raw embeddings do not select
the expert.

The current source-held comparison covers all276 primary cases/84 groups, with
15 valid Sol views and one retained failed Sol slot; remaining cases keep v72.
The cached Sol subset is selected older diagnostic data, not a fresh or complete
Sol benchmark. All held-source siblings stay outside teacher and gate fitting.

Single-source proposals are allowed only with all-original safeguards and held-
source evaluation. In this case the rule transfers between two different held
sources. Universal protection is stronger than actual-only replay and performs
better here: all99 original cached inputs request no independent review and are
unchanged for every possible Sol label in each fit.

Directly taking all available Sol labels has the same225/276 primary accuracy,
but makes two primary regressions and loses seven original cases (92/99).
The selected semantic gate makes two corrections/no losses and keeps99/99.
Even oracle selection between the base and these limited Sol labels reaches at
most227/276, so the current extra-view cache cannot itself meet235/276.
