## Design decisions

Correct-label availability is an optimistic bound, not proof of valid evidence.
Sparse policy failure motivates isolating the observer model. A fresh Luna arm
helps distinguish a model change from differences between a cached and fresh
run. Only the observer identity differs between fresh arms. Query human labels,
previous verdicts and error/control status never enter model prompts. Selected
training-only diagnostic accuracy is not population/generalization accuracy.
