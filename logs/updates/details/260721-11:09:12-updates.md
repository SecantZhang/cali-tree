# 260721-11:09:12 — Raw per-rater targets in calibration pipelines

## Motivation
The calibration nodes rejected Dataset outputs configured with `aggregation_method=none`, even though raw per-rater scores were intentionally retained. The desired pipeline should calibrate from those individual observations without manufacturing a consensus score.

## Changes
- `vejudge/interface/node_calibration`: removed the unaggregated-label rejection; preserved raw scores and per-rater gaps in adversarial results; expanded each item's raw ratings into repeated fitter observations for rule-tree and semantic-tree calibration.
- `vejudge/core/calibration/debate`: added raw-label grounding, keeping the full rating list in the human-proxy prompt without averaging it; added grouped leave-one-out evaluation so every rating for a held-out item stays out of its training fold.
- `vejudge/core/prompts/d2_human_proxy_debate.py`: bumped the prompt to v2 and added explicit unreduced-score instructions.
- `web/src/panels/RightPanel/secondary`: rendered raw human score/gap lists and allowed raw target lists in rule reports.
- `vejudge/interface/interface.md`: documented raw-rating calibration and grounding semantics.
- `tests`: replaced rejection assertions with raw-observation, grounding, prompt, and report coverage.

## Design decisions
Raw ratings are separate training targets with the same item features, not averaged labels. Leave-one-out remains item-level rather than observation-level to prevent an identical item's sibling ratings from leaking into training. A one-score-per-item debate cannot converge numerically to several conflicting targets, so raw mode grounds the human proxy with the complete rating list and uses score-stability convergence; the downstream fitter is where every rating becomes its own supervised observation.
