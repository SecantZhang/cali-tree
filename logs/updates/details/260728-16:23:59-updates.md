# 260728-16:23:59 — Document Cali-Tree v1–v4 metric comparison

## Motivation

The Cali-Tree documentation described the prompt variants but did not give a consolidated,
metric-by-metric report showing how v1, v2, v3, and v4 differed or why v2 remained the
default.

## Changes

- `docs/calitree.md`: added a semantic comparison of all four prompt bundles.
- Added small-run train/test accuracy, balanced accuracy, per-class recall, confusion
  matrices, prediction distributions, per-editor accuracy, merge outcomes, call counts, and
  token usage.
- Added the full 1,200-case v2 baseline/Cali-Tree/selective report with confidence
  intervals, class recall, and human-agreement slices.
- Documented comparability limitations: v1 used a different sampler, and v4 also changed
  optimization/conflict settings.

## Design decisions

The v2/v3/v4 table uses runs with identical three-case training and eleven-case test sets.
The corrected v1-era run is retained for completeness but explicitly marked non-comparable.
Metrics are reported without ranking v4 by its unstable balanced accuracy, since the small
test set has only one `partial` and one `yes` case.

## Verification

- Recomputed every table entry from the four run-scoped `calitree_train.json` reports and
  the combined 1,200-case summary.
- Confirmed that the v2/v3/v4 train and test item-ID sets are exactly equal.
- `git diff --check` passed.
