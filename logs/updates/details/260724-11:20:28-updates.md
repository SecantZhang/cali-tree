# 260724-11:20:28 — Add edit-aware evidence judging and calibration

## Motivation

Add a reproducible decomposition-and-attention path that evaluates localized editing evidence, learns from optional unit-level human feedback, and compares against the existing whole-video judge without changing existing workflows.

- `vejudge/evidence/`: added JSON-safe evidence contracts and a local content-addressed artifact store backed by transactional SQLite manifests, units, artifacts, measurements, provenance, and cache state.
- `vejudge/preprocessing/edit_decomposition.py`: added FFmpeg preflight, OTIO/assembly timeline reconstruction, rendered scene detection, boundary reconciliation, shots, boundaries, sequences, audio events, artifact extraction, media measurements, stable IDs, fallbacks, warnings, and content/config/version cache identity.

- `vejudge/interface/`: registered explicit decomposition, rubric, area-judge, aggregation, unit-label, and edit-aware calibration nodes; added evidence-root media confinement and node result metadata.
- `web/`: added socket mappings, parameter forms, node components, evidence/area result panels, and a full mocked edit-aware Playwright workflow.
- `workflows/examples/edit_aware_calibration.json`: added an example with an existing whole-video baseline branch, four area-rubric branches, fixed aggregation, raw evaluation, edit-aware calibration over both signal families, and held-out calibrated evaluation.
- `README.md`, `docs/`, `run/`, and `pyproject.toml`: documented the architecture, research promotion gate, optional video dependencies, and actionable FFmpeg setup/preflight.
- `tests/`: added evidence-store, OTIO, fallback, real-media extraction, selection, aggregation, checkpoint, unit-label, calibration, registry, API, media-confinement, and interface coverage.

## Design decisions

The new path is explicit and additive, so saved whole-video workflows require no migration. Media remains in immutable content-addressed files while SQLite stores queryable metadata and paths. Unit calls are independently checkpointed using evidence, unit, rubric, prompt, and engine identities. Missing calls reduce coverage instead of being imputed as passing. Unit mappings activate only with sufficient cross-video label support, and video partitions are inherited by all child units to prevent leakage. Prompt rewriting and vector retrieval remain outside v1; numeric calibration versions are immutable.
