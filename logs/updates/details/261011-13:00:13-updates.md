## Motivation

The user requested a new interactive architecture flowchart in HTML, explicitly forbidding reuse of the previous visualization.

## Changes

- Authored `docs/visualizations/calitree-system-flowchart.html` from scratch as a complete offline document. No previous visualization source was read, copied, exported or embedded.
- Added three connected diagrams: optimization of one leaf, exact saved-leaf inference, and system/shared/compatibility boundaries, based on current sources at commit 6765741e.
- Added 36 keyboard-accessible node buttons, 37 labeled directed edges, decision diamonds, repair loops and a separate dashed reference-label route.
- Added source/inputs/outputs/rules inspector, connected-component navigation, zoom/fit, drag pan and detail toggle. Current algorithm, model stages, code aggregation/acceptance and preserved APIs are clearly separated.
- Documented offline opening in the visualization README. Kept the earlier inline visualizations unchanged.

## Design decisions

Standalone HTML has a restrictive CSP, no remote resources, no host API dependency and no API/network calls. Current source facts determine architecture labels; no new experiments or invented case measurements. Use readable labels rather than shrinking the entire chart on narrow devices; the canvas is pannable, while the inspector stacks below. Reveal the complete final-verification path on desktop. Generic stage navigation is labeled component navigation because it is a graph with branches, not a measured linear run. No production code, compatibility format, historical results, commits or pushes were changed.
