## Design decisions

Use at most two parent checks and preserve the original whole instruction as the immutable requirement. Code assigns equal conserved parent facet mass; models cannot set weights. Parent coverage maps and empirical gates provide evidence, not semantic proof. Parent acceptance requires independently fresh five-draw child baselines, no member/selection regression and all strict five-draw parent robustness gates. Semantic auditing remains disabled. Root family parsing is a fixed label-blind prototype component; the accepted parent/scope table is fitted, not a learned general classifier. Unsupported/rejected families use a fresh label-free seed. Binding/routing occur once per case; repeated draws assess the fixed bound program. Final evaluation labels enter only post-execution metrics. Selection freezes before every evaluation request.

Reserve 88 calls/110,592 tokens before search for final parent/fallback and fresh baseline inference at the existing four-check maximum. Global ceiling 300/384,000; scope limits 32 search/48 final. Fifteen leaf rounds remain bounded by those budgets. One HTTP attempt per durable slot, no schema repair, no model substitution, retained failures/interruption charges and stop after three consecutive transport failures.
