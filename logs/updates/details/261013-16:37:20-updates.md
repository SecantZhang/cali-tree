# 261013-16:37:20 — Benchmark a strong flat judge on twelve balanced AURORA cases

## Motivation

The user requested a strong flat-judge accuracy baseline after reverting optimizer
exploration. Keep the restored implementation intact and run a small controlled
benchmark entirely under logs.

## Changes

- Added a standalone benchmark, fixed prompt, source snapshot, sampled manifest,
  call estimate, authorization and verification records under
  `logs/exps/261013-flat-sol-high-balanced12/`.
- Sampled four No, four Partial and four Yes AURORA-editor outputs from official
  seed-42 test tasks, spreading across all eight task categories, with distinct
  source pixels. Excluded the prior twelve fitting sources and reserved holdout.
- Used GPT-6.1 Sol with high reasoning, four workers, one source-first presentation
  and one direct overall judgment per case. No optimization, merges, voting,
  exemplars, editor priors, or fitted score thresholds.

## Design decisions

- Verified image input, structured output, Chat Completions and high reasoning
  support using official OpenAI documentation before live execution. The existing
  restored provider supports this profile; no production code change was needed.
- Human references remain released mean-score classes at 0.5/1.5, not majority
  votes. Do not pass scores, labels, case IDs or editor names in judge payloads.
- Freeze sample/prompt/model before calls, retain failures without retries, and
  replay recorded results without additional calls. Empty explanatory text alone
  does not invalidate a valid label.
- Historically queried sources may be included; this is a small baseline
  diagnostic, not an untouched population test or repeat-robustness study.

## Verification

- Offline preflight: image/source/prompt/code hashes, class balance, source
  independence, exclusions, and API wire settings verified; zero calls.
- Live: twelve attempted and completed responses; no failures or unresolved cases.
- Accuracy 8/12 (66.7%); No recall 4/4, Partial 3/4, Yes 1/4. Three Yes references
  became Partial and one Partial reference became Yes.
- Approximate Wilson interval 39.1%–86.2%; twelve cases cannot establish population
  accuracy. No matched-method improvement claim is made.
- Successful-response usage: 15,050 input and 3,085 completion tokens.
- Verified every inference payload contains only the instruction and labeled
  source/edited media; response model matches the frozen single-model profile.
- Offline replay matches exactly with zero new API calls.
- All tracked non-log files still match cleanup commit 6765741. No interface/web
  changes or restart of the optimizer exploration.

## Follow-ups

The flat rubric/model combination under-rates the sampled Yes cases. Inspect
scope and satisfaction tolerances on separate development data before any future
calibration. Do not tune the prompt on this measured sample and keep calling it
an unbiased baseline.
