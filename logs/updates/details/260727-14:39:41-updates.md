# 260727-14:39:41 — Add workflow-native Cali-Tree image calibration

## Motivation

Implement the Cali-Tree method from the attached CIKM demo paper as an inspectable,
checkpointed image-judge calibration workflow, using the paper's public ImagenHub task
collection while retaining VEJudge's existing video paths.

## Design decisions

The paper defines the hierarchy qualitatively but omits numeric construction and routing
details. The implementation therefore exposes the requested 0.90-to-0.70 similarity schedule,
three-step limit, 100% full-merge rule, and 80% partial-merge rule as configuration and labels
them as an interpretation rather than exact reproduction. Splits are grouped by task UID so
all editor outputs remain on one side. SC drives the class target; PQ remains provenance.
TextGrad is lazy-loaded and pinned as an optional dependency, with its side log redirected
inside the run directory. No live model defaults are permitted on the Cali-Tree example.
