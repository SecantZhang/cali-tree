# 260902-23:57:59 — Prediction-conditioned CaliTree beats plain GPT-4o

## Motivation

The guarded behavioral pilot was safe but only tied the plain judge because its
target-bearing failure-mode key fragmented nine fit cases into eight leaves. Most leaves had
no independent support, and inference could not reproduce a grouping that depended on the
hidden target. The next algorithm needed to let the top prompt predict the leaf without label
leakage and still preserve safe fallback behavior.

## Algorithm changes

- Added `leaf_grouping=residual_context`. The top GPT-4o prompt predicts first; routing backs
  off through `(editor, operation, prediction)`, `(editor, prediction)`, `(operation,
  prediction)`, and `(prediction)` according to fit and validation support.
- Persisted the target-blind partition and exact context routes. Rejected or unsupported
  contexts fall directly to the validated root; semantic similarity cannot divert them to a
  different residual leaf.
- Tightened leaf routing from tie-or-better to strict held-out improvement.
- Added a Pareto prompt cascade: the optimized prompt can serve a top-prediction cohort only
  after at least one fit correction, zero fit regressions, and zero validation regressions.
- Preserved routing keys in the prediction cache and implemented the same two-stage top-label
  route in the standalone judge node.
- Added configurable pilot train/test ratios, task grouping, and test-group offset so a clean
  larger holdout can be run without changing frontend code.

## Live evidence

- The 12-train/24-test diagnostic formed two coarse leaves. Its supported `top=no` leaf tied
  100% vs 100% on two validation cases and was correctly rejected; CaliTree tied the plain
  judge at 83.33%.
- The 58-train/24-test development pilot activated one Pareto route and improved accuracy from
  20/24 (83.33%) to 21/24 (87.50%), balanced accuracy from 61.90% to 95.24%, and macro-F1
  from 57.44% to 77.44%.
- The clean confirmation used all 232 official training cases and a disjoint 120-case test
  sample containing 15 complete tasks at group offset 4. CaliTree scored 91/120 (75.83%) vs
  the plain GPT-4o judge's 84/120 (70.00%). Balanced accuracy improved 46.39%→53.51%,
  macro-F1 44.24%→49.03%, and ordinal MAE 0.1625→0.1292. All predictions were valid.
- Paired attribution: train-only editor-prior leaves produced the seven-case accuracy gain;
  the prediction cascade kept accuracy at 91/120 while improving balanced accuracy from
  45.88% to 53.51%. The paired comparison had 13 wins and 6 losses (`p=0.167`, exact
  McNemar), so a larger confirmation is still appropriate before production promotion.
