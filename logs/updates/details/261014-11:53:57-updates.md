# 261014-11:53:57 — Learned policy to semantic conditions with accuracy-preserving prose execution

## Motivation
The active user goal asks for a transformation from learned policies to semantic decision rules that predicts the same or better accuracy on the same local cases. The prior universal-gate interpretation changed successful policies and reduced accuracy; this work derives the actual learned interactions and tests their natural-language interpretation separately.

## Changes
- Added `SemanticConditionPolicy` (`Calibrator` subclass): compile each positive-weight shared v6 boundary into minimal sufficient conjunctions of named semantic states, combine alternatives with OR, preserve ordering/unknown/missing/uninspectability behavior. Execution contains no weighted sum, numeric cuts, IDs or reference lookups.
- Added natural-language rule rendering with explicit per-feature ordered semantic meanings; all twelve Sol/Luna/mini shared teachers are translated and retained.
- Added grade-blind `SemanticPolicyExecutor` and versioned v8 prompt. It categorizes cached instruction/contract/aspect/quality prose into named states, then the deterministic semantic rule gives the label. No original grades, score, weights, cuts, teacher case predictions, human labels, examples or images enter those model calls.
- Added versioned v9 refinement of shared scope and materiality definitions, derived from the first-pass disagreements. Scope requires affecting the intended original target; bounded residual shortfalls are separated from material incompleteness. No case names, specific object rules or exact instruction checks are used.
- Added frozen-protocol runners, domain certificates, source snapshots, independent grade-free request/prediction/metric audit, per-case reports, seven offline tests and docs/replay commands. Earlier experiments and production defaults are unchanged.

## Design decisions
The exact compiler preserves the teacher's actual decision function rather than imposing new universal vetoes. Named-state conversion retains the original ordinal information and provides a verified reference, but is not treated as new semantic evidence. A separate live prose-only test demonstrates execution without seeing those states/grades. Definitions are refined locally from teacher disagreements; these are optimization cases, not held-out data. Four fixed source failures remain unresolved, no new image judgment is made, and all versions remain visible.
