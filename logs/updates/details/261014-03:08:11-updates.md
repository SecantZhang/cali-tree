## Design decisions
The router receives fixed instruction-derived descriptors only, never labels, evidence grades, words, image hashes, or IDs. All supervised fits remain separate per group. Selection jointly maximizes accuracy and macro-F1 with explicit all-class support. Unknown physical facts remain unknown; a separately supported evaluation-policy branch handles the inability to verify the result. This distinction addresses the G1 abstention bottleneck without a case exception.
