## Design decisions

Supporting facts inform classification of the original outcome; they do not earn edit completion credit. Repeated estimates of r1 do not become separate requirements. Confidence is diagnostic, not an optimization feature or acceptance veto. Parent learned aggregation is an explicit experimental calibration mode, separate from the unchanged default v7 arithmetic.

Capability scopes come from fitting instructions alone and supply context features. They are not a hardcoded dataset router. Literal scope support does not establish comprehensive semantic or paraphrase correctness. Training uses one independent source group per case. The development selection set is iteratively observed and is not presented as an untouched test.

A frozen parent must pass >90% development selection and >=.8 per-class recall before dispatch. Completion additionally requires at least 46/50 actual correct parent-majority predictions on the reserved H cases, using three fresh draws, with unresolved/uncovered/fallback cases counted incorrect. No final outcomes can retune the selected candidate.
