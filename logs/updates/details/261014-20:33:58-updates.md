# M2–M4: scalable semantic learning and audited routing

- Implemented a versioned packed-coverage learner, closed physical feature
  projection, two local candidate behaviors per batch, source-grouped pooled
  baselines, instruction-only scope selection, pooled fallback, and frozen
  inference bundles. No legacy/default pipeline was replaced.
- M2 verifies fitting, restoration, and scalar reference scoring at 12,24,48,96
  rows. The actual full-48 optimum matches exact independent scoring over
  1,131,312 retained region pairs. The search is bounded, not globally optimal.
- Found and fixed two defects while verifying: negative side constraints could
  supply false progress; Partial proposal ranking could prune a complementary
  witness in favor of Yes coverage. The latter failed a known three-atom
  synthetic rule at 80/96; v3 recovers 96/96. All v1/v2 results remain preserved.
- Collected frozen M1 v2 evidence on the 48 training cases: 96 attempts,
  48 compiled programs, 47 observations, one retained G3C05 transport failure.
  Reused the existing twelve development records. Cumulative extraction calls
  are 143 including the retired M1 v1. Reserved-final calls: zero.
- Independent collection audit verifies 96 call identities and 366 question
  bindings. No labels or previous answers entered extraction payloads.
- Final pooled fit: 29/48 in sample. Grouped OOF: pooled 16/48, routed 18/48.
  Routed recalls No/Partial/Yes are 7/16,2/16,9/16; 15 unresolved. Supplementary
  development: pooled 7/12, routed 6/12. Cached same-case flat context: 30/48.
- Independent M3/M4 audit checks 15 fits,30 artifacts,504 predictions,4 outer
  folds,16 inner source separations,and20 selected route gates. 97 scoped tests
  pass; all collection/baseline versions replay with zero new model calls.
- Routing is functionally verified but not deployment-qualified: the gain is
  only three paired OOF wins versus one loss, and the development set regresses.
  The active inference fallback is measured, and the 29/48 oracle is labeled
  diagnostic rather than claimed as routed accuracy.
- Added per-candidate scope proposals, soundness review, iteration comparisons,
  exact reference certificates, and `docs/calitree_m2_m4_semantic_baselines.md`.
  M5–M9 remain future work. Poor evidence/guard transfer should be reviewed
  before assuming merging will provide an accuracy improvement.
- Final completion audit maps all 25 M2–M4 requirement groups to current code,
  tests, and artifacts. A fresh run passes all 97 scoped tests. Every saved
  candidate scope and outside-fit metric was reproduced; 814 earlier artifacts
  and all 120 sealed M1 artifacts remain byte-identical. Final-test predictions
  remain zero. Separate milestone audits and a completion seal preserve this
  evidence; predictive qualification remains explicitly unestablished.
