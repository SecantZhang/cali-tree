# 260729-13:58:08 — Add two-cutpoint Rubric-Lite domain adaptation

## Motivation

The frozen ImagenHub rubric transferred to EditInspector only as a selective `yes`
detector. Its full-coverage accuracy and partial-class F1 were too low, while the
hierarchical Cali-Tree machinery remained hard to justify. This iteration tests the
smallest possible supervised adaptation: keep one global rubric call and learn only the
two boundaries of its visible-evidence score.

## Changes

  deterministic stratified out-of-fold evaluation for the two global ordinal thresholds.
- `vejudge/interface/node_calibration/rubric_lite_nodes.py`: added workflow-native Fit and
  Apply nodes. Fit emits a two-number artifact plus development diagnostics; Apply changes

## Design decisions

The fitted model contains no tree, leaves, embeddings, clustering, routing, editor
identity, instruction features, or verifier. It enumerates the finite score cutpoints,
requires a recall floor for each represented class, and selects macro F1. Five folds are
used only as a development estimate; the final deployment pair is fitted on all 392
calibration cases.

The old 312-case confirmation set is now part of model selection and is no longer treated
as untouched evidence for this candidate. The remaining 391 cases are explicitly named
`final` and excluded from the frozen artifact. A separate final workflow prevents
accidental recalibration or duplicate billing.
