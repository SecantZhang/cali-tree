# 260729-16:52:46 — Preregister the full Rubric-Lite v4 benchmark

## Motivation

Rubric-Lite v4 had a 600-case frozen confirmation result but had not been evaluated under
one frozen protocol on all 1,200 public ImagenHub held-out cases. A full evaluation is
needed for a direct, task-matched comparison with CaliTree v2.

## Changes

- `workflows/examples/rubric_lite_imagenhub_full_1200.json`: added a one-call frozen-v4
  workflow covering all 150 held-out tasks and eight public editors, with no training or
  verifier node and an explicit selective human-review decision.
- `run/run_imagenhub_rubric_lite.py` and `.sh`: added gated dry/live execution, exact
  checkpoint compatibility validation, node-key normalization, preflight call accounting,
  full graph artifacts, and resumability.
- `docs/experiments/rubric_lite_v4_full_1200_protocol.json`: froze the dataset, artifact,
  engine, checkpoints, metrics, and interpretation rules before new results.
- `run/README.md`: documented the new runner.

## Design decisions

The full-coverage one-call v4 result is primary. The optional boundary verifier is excluded
because it was selected on only one half and would add a different inference path. The
frozen perfect-evidence review policy is evaluated separately and must always be reported
with coverage. Existing judgments are reused only when the exact prompt hash and engine
configuration match. Normalizing prior node IDs is safe because the checkpoint suffix
hashes the complete system prompt and item ID.
