# 260728-00:37:47 — Guard Cali-Tree optimization and validate larger samples

## Motivation

Improve the general prompt-optimization framework's train and held-out accuracy without
letting one-case leaves or merge prompts overfit a tiny sampled training set, then validate
the improvement with billable image-judge calls on a larger public ImagenHub sample.

## Changes

- `vejudge/core/calibration/calitree.py`: added a balanced global warm start, true
  complete-link clustering, target-blind case-centroid routing, calibrated route thresholds,
  an internal generalization floor, a universal global fallback, singleton routing guards,
  rejected-pair deduplication, and balanced/per-label metrics.
- `vejudge/interface/node_calibration/calitree_nodes.py`: added deterministic label-stratified
  internal validation, concurrent/checkpointed judging, v2 prompt selection, batched routing,
  and prompt-hashed prediction reuse across train → route.
- `vejudge/interface/node_db/sampling.py` and Dataset node/UI: added
  `split_label_stratified`, balancing small official-train quotas while preserving natural
  held-out prevalence.
- `vejudge/core/prompts/templates/calitree_v2/` and TextGrad adapter: added a versioned
  Semantic-Consistency-only rubric and reusable, target-leakage-safe optimization prompts.
- `web/src/panels/RightPanel/secondary/CaliTreeWorkbench*`: exposed balanced accuracy and
  the global fallback state.
- `run/run_e2e_tests.sh`, `web/e2e/global-setup.ts`, and `web/playwright.config.ts`: made the
  E2E runner work with a shared parent virtualenv and configurable per-worktree ports.
- `docs/calitree.md`: documented the guarded v2 algorithm and live 1%/5% results.

## Design decisions

The official train/test boundary remains immutable. Small training quotas are class-balanced,
but test quotas retain source prevalence. Merge acceptance now requires both covered-case
accuracy and balanced performance on an internal official-train validation slice; failed
specializations fall back to the global TextGrad rubric. A cached routed result is reusable
only when its item ID and prompt-content hash match, so it prevents duplicate model calls
without changing routing or consulting a label.

The primary requested metric is ordinary accuracy, but balanced accuracy and per-label recall
are reported alongside it because the public test distribution is no-heavy.
