# 260729-12:01:39 — Add ordinal Rubric-Lite and boundary verification

## Motivation

The original Cali-Tree hierarchy reaches strong selective accuracy but is complex, while the first Rubric-Lite versions did not preserve all three classes reliably. This iteration tests a simpler general formulation: one global multimodal rubric, two train-fitted ordinal cutpoints, and an optional targeted verifier only for cases near the partial boundary.

## Changes

- `vejudge/core/calibration/rubric_lite.py`: added deterministic ordinal labeling, threshold application, and train-only threshold fitting with an explicit represented-class recall floor.
- `vejudge/core/prompts/templates/rubric_lite_v3/` and `rubric_lite_v4/`: added versioned three-score prompts; v4 makes source-to-edited change evidence, exact instruction fidelity, and local source preservation explicit.
- `vejudge/interface/node_calibration/rubric_lite_nodes.py`: added v3/v4 training, validation/refitting, report metadata, exact dry-run estimates, and the score-gated `rubric_lite_boundary` executor.
- `vejudge/interface/node_calibration/calitree_nodes.py`: added structured ordinal-result parsing and inference-time application of the fitted global cutpoints.
- `web/src/` and `workflows/examples/rubric_lite_imagenhub.json`: registered the boundary node, exposed ordinal controls and reports, and updated the example to route ambiguous cases through the verifier.
- `tests/` and `web/e2e/`: added coverage for threshold fitting, class preservation, v3 parsing, inference, boundary dry/live behavior, registry metadata, and the workflow graph.

## Design decisions

The learned model intentionally uses only three general visual-evidence scores and two global thresholds. It does not use editor identity, task UID, instruction clusters, or label-frequency features, reducing leakage and dataset-specific behavior. Thresholds are fitted on task-grouped training data and constrained to retain every represented class. The boundary verifier is optional and target-blind: it runs the independent v1 rubric only when the primary ordinal score clears a configured threshold, and only a `partial` verifier result overrides the primary result.

The frozen v4 10% development run reached 86.67% full-coverage accuracy and 45.45 partial F1. On the separate 600-case confirmation half it reached 82.17% accuracy and 29.51 partial F1, within 0.66 percentage points of the full Cali-Tree v2 full-coverage accuracy but without improving confirmation partial F1. The verifier was therefore added as a small conditional correction rather than growing another hierarchy.
