# Structural decision-program optimizer and CaliTree leaves

## Motivation

Optimize explicit reusable checks and their bindings using model feedback, measured
selection, and fixed requested-outcome aggregation. Preserve the user's current
shared-tree progress on the new codex/decision-program-optimizer branch.

## Changes

- Added critical/core/decision: typed programs, frozen checker templates, label-free
  compilation and binding, atomic execution, dependency validation, aggregation,
  content-addressed artifacts, and durable single-attempt call budgets.
- Added critical/core/optimization/program: abstract contracts, immutable edits,
  training feedback, model proposals and separate label-free audits, repeated
  evaluation, guarded acceptance, bounded beam search, and an offline demonstration.
- Added CaliTreeBuilder.build_program_leaves, a program leaf controller, portable
  leaf bundles, and direct inference with saved execution contracts.
- Added a preflight/live/resume/report runner, versioned templates, focused tests,
  implementation documentation, run instructions, and a live pilot report.
- Corrected overstrict identifier and source-quote validation exposed by the live
  pilot, with regression tests. Preserved original artifacts and completed only
  unattempted final checks using the frozen selected program and shared budget.

## Design decisions

Programs are authoritative; prompt prose is not recompiled during reload. Requested
outcomes are separate from supporting evidence. Unknowns remain unresolved and
count against full-coverage metrics. Candidate acceptance protects coverage and
per-class recall. Selection and evaluation cases never supply repair feedback.
Parent merging, learned aggregation, and UI changes remain deferred.

The branch was created from e27833f without resetting or stashing the user's staged
and uncommitted progress. No commit or push was requested or performed.
