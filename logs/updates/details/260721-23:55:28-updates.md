# 260721-23:55:28 — Add guarded graded semantic-tree calibration

## Motivation

The frozen M5 evaluation showed that the semantic tree was too sparse to express nuanced
calibration decisions, but increasing tree size without model selection risked fitting the
26 training videos and worsening the seven-video validation result.

## Changes

- `critic_extraction.py`, `rubric_bank.py`, `concept_tagging.py`, and `ontology.py`: added
  eight fixed target-blind M5 rubric decisions, explicit item-quality versus judge-reasoning
  scope, and signed evidence strengths while retaining compatible boolean outputs.
- `semantic_tree.py`: changed semantic fitting to weighted absolute-error split gain and
  robust weighted-median leaves; added controlled feature subsets and depth-three capacity.
- `evaluation_support.py` and `semantic_selection.py`: added training-only median imputation
  and item-grouped inner-LOO selection over feature set, depth, and leaf mass. Semantic
  capacity must improve training CV by at least 0.01 over base-only to be selected.
- `cl_semantic_tree_node.py`: integrated the fixed/debate rule bank, graded evidence,
  imputation diagnostics, train-only model-selection audit, and explicit confirmation that
  validation labels were not used.
- `cl_rule_eval_node.py`: fixed the verdict so a qualifying semantic model can beat global
  bias even when score-only linear calibration does not independently clear the threshold.
- `web/`, `interface.md`, workflow JSON, and tests: exposed the selected capacity and rejected
  semantic-gain warning, raised the workflow capacity, documented behavior, and added unit/UI
  coverage.
- `docs/calibration_prompt_distillation.md`: recorded both the overfit full-rule fit and the
  guarded frozen-holdout result.

## Design decisions

The independent critic sees deployment-available video evidence and frozen questions, never
held-out human labels. Missing critic evidence is imputed only from training-video medians.
Capacity is available up to depth three, but a larger feature set is not selected for a
sub-0.01 training-CV fluctuation. This intentionally treats a simple selected tree as an
evidence outcome rather than forcing semantic splits for appearance.

The approved live rerender reused completed judge/debate checkpoints. The unconstrained
all-feature linear fit reached 0.959 training MAE but regressed to 1.226 held-out MAE. The
guarded semantic path selected a one-split robust tree and reached 0.921 training MAE and
1.062 held-out MAE. That improves the prior semantic result by 0.053 and 0.052 respectively.
Against global bias (1.176), the 0.114 held-out gain has an item-grouped bootstrap 95% CI of
`[0.003, 0.206]`; the 0.052 increment over score-only linear remains inconclusive on seven
validation videos (`[-0.040, 0.136]`).

## Follow-ups

Meaningful semantic branching still requires a larger and more diverse labeled sample. The
seven-video validation result supports the guarded calibrator over global bias, but does not
yet establish that semantic features add beyond score-only calibration.
