# 261006-21:05:02 — Test combined versus separate visual decision checks

## Motivation

Test the user's hypothesis that independently evaluated visual rules are more stable than fitting every criterion into one prompt. The user approved a twelve-case GPT-6 Luna paired pilot with five repeats per format and cumulative ceilings of 400 calls and 409,600 completion tokens.

## Design decisions

Change execution format while holding criteria fixed. Combined returns all observations and outcomes together. Separate execution isolates each visual fact and gives the fulfillment call only observations, not images. Both use the same required-unknown guard and requested-outcome aggregation. Repeats are not independent cases.

An initial parser defect rejected empty explanatory reason strings. Fixed the metadata validation, retained all prior paid slots and reprocessed the same responses without recompilation. All initial banks then failed preparation; before any execution, the protocol was amended to allow one label-blind semantic repair per case within the same budget. Identical proposals reuse their original audit. No evaluation outcome informed repair or selection.

Three repaired banks passed, nine remained audit-rejected. Audits are model judgments, not proven semantic validity. The accepted banks still contain coarse progress/completeness questions rather than fully fine-grained visual predicates. This limits the test of the user's intended decomposition and is explicit in the report.
