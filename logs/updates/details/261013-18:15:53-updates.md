# 261013-18:15:53 — Separate-batch evidence calibration and cached evaluation

## Motivation

Implement batch calibration on a separate class-balanced AURORA sample, freeze
the mapping, and compare the same twelve cached evidence records against the
saved flat and uncalibrated judges.

## Changes

- `critical/core/calibration/evidence_batch.py`: Calibrator subclass implementing
  L2 multinomial classification of structured evidence states and TF-IDF evidence
  text, calibration-only three-fold C selection, portable JSON restore and fixed
  No/unresolved guards.
- `run/calitree_batch_calibration.py`: deterministic source-disjoint 36-case
  official-training sampler; preflight/live/replay; unchanged single-call observer;
  immutable registry publication before cached evaluation; three-way metrics,
  fitting/CV diagnostics and reports.
- `tests/unit/calitree/test_batch_evidence_calibration.py`: no-API tests covering
  text sensitivity beyond identical states, metadata exclusion, source separation,
  portable probabilities, protected uncertainty, and test-label independence.
- `docs/calitree_batch_evidence_calibration.md`, `run/README.md`: protocol/usage.
- `logs/exps/261013-batch-evidence-calibration-v1/`: frozen cases/code, estimate,
  durable observations, CV predictions, model registry/seal, report, analysis,
  full histories, exact replay and audit script/results.

## Design decisions

Use 36 AURORA-editor outputs, twelve per aggregate-reference class, from official
seed-42 training tasks. Exclude the twelve evaluation source groups, earlier
twelve fitting groups, and reserved fifty-case holdout. Spread sampling across
all eight task categories. Source-pixel groups are unique in fitting and disjoint
from evaluation.

The evidence prompt and GPT-6.1 Sol/high observer remain unchanged. One call and
SOURCE-first presentation per new calibration case; four API workers; no retries.
Fitting and all twelve evaluation predictions are offline. No separate judge
model, test image calls, or test-label fitting is introduced. Vocabulary/scaling
are fitted separately inside each CV fold. The artifact is registered before
evaluation and is not tuned on its results. The original optimizer stays unchanged.

## Follow-ups

The statistical calibration baseline did not generalize to these twelve cases.
Calibration records judged Partial contained five human-No/eight Partial/one Yes;
evaluation records judged Partial contained zero No/three Partial/four Yes. This
error-distribution mismatch and the training/test gap are consistent with poor
transfer; they do not establish that every batch calibration method will fail.
Probabilities are not validated confidence estimates. No optimizer goal is resumed
and no additional model/variant is fitted on the evaluation outcomes.
