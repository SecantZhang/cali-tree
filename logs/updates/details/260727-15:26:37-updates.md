## Design decisions

The public setup does not fabricate or silently omit individual assets. It downloads all
eight editor directories currently present at the cited ImagenMuseum location and records
all nine rating columns as provenance. Users with a separately obtained Imagic directory
can still opt into it.

The live sample uses repeat 3 (seed 44), because the deterministic 1% selection contains
three training and eleven test cases; repeats 1 and 2 would contain only one training case.
The successful run explicitly configured `gpt-4.1-mini` for both image judging and TextGrad
optimization, `text-embedding-3-small` for semantic routing, 512 completion tokens per model
call, three optimization steps, and the resulting 4,608-token optimizer budget.

An initial Gemini run at 256 tokens completed but truncated six structured judgments. A
fresh 1,024-token Gemini attempt was stopped after one image request remained in transport
retries through multiple five-minute timeouts. Both artifacts remain available for audit;
the final GPT run was fresh, completed all nodes, and produced zero invalid judgments.
