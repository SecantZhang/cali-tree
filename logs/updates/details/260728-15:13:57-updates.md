# 260728-15:13:57 — Add reliability-calibrated Cali-Tree and confirm publishable accuracy

## Motivation

The earlier 10% result used all 232 official training cases but did not establish whether a
90% operating point generalized beyond the development subset. The calibration pipeline
also needed explicit handling for task leakage, human-label disagreement, semantic
pre-merging, and deployable abstention.

## Changes

- `vejudge/interface/node_db/sampling.py` and Dataset node: added independent train/test
  ratios, task-grouped sampling, and deterministic group offsets; offsets 0 and 1 form
  disjoint 75-task halves at a 50% test ratio.
- Cali-Tree builder and workflow executor: optimized one task-level leaf across all editor
  outputs, added target-blind semantic operation pre-clustering, complete-link merge guards,
  conflict-aware branching, deterministic routing fallback, and persisted tree artifacts.
- Consensus calibration: added task-grouped capacity selection over candidate patterns,
  editor/operation hierarchies, conservative editor priors, and an option to fit calibration
  only on training cases where all three SC raters agree.
- Selective calibration: fitted editor reliability only from filtered official training
  labels and accepts only three-way-unanimous predictions from sufficiently supported,
  reliable editors; persisted each decision through route and eval nodes.
- Interface: exposed split offsets, agreement filtering, selective-policy parameters,
  coverage/abstention, active editors, human-agreement metrics, tree details, and image cases.
- `docs/calitree.md`: documented the corrected 232/1,200 split semantics, architecture,
  billable experiments, limitations, and confirmation result.

## Design decisions

The 600-case offset-0 half was treated as development data. It selected the fixed selective
thresholds: consensus support 3, editor support at least 10, and 85% editor accuracy on the
181 unanimous-label training cases. The disjoint offset-1 half was then evaluated without
changing those settings.

Adding the routed tree as a fourth consensus voter was rejected because it did not improve
the development half. The tree remains responsible for prompt specialization/routing while
the three independent rubric variants provide the final conflict signal. Disputed human
labels remain in all full-coverage reports; filtering applies only to calibration fitting,
not to evaluation.
