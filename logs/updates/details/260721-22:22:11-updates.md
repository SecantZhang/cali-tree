# 260721-22:22:11 — Establish meaningful held-out calibration gain

## Motivation
The latest calibration run had unstable multi-state negotiations, overly collapsed semantic questions, and no honest comparator separating score calibration from incremental semantic-rule value. The corrected system needed to demonstrate a meaningful held-out improvement over global bias without attributing that gain to rules unless the data supported it.

## Changes
- `vejudge/core/calibration/debate/runner.py`: detect repeated score cycles of any period, retain the original score for oscillating unresolved debates, and preserve convergence diagnostics.
- `vejudge/core/calibration/debate/eval/critic_extraction.py`: make independent-critic extraction video-grounded when the selected engine supports media and version the critic behavior.
- `vejudge/core/calibration/debate/eval/question_bank.py`: preserve 6–10 distinct observable candidate rules instead of over-merging non-duplicates.
- `vejudge/core/calibration/debate/eval/rule_fit.py`: add a score-only linear calibration comparator alongside global bias and score-plus-rule models.
- `vejudge/interface/node_calibration/`: checkpoint candidate mining per item, extract candidates concurrently, and invalidate stale evaluation caches with the new version.
- `vejudge/interface/node_eval/cl_rule_eval_node.py` and the rule-evaluation detail panel: separately report score-calibration improvement over bias and semantic-rule increment over score-only calibration, with bootstrap confidence intervals and honest verdict text.
- `vejudge/interface/server/run_manager.py`: give every resume attempt a unique public run ID while reusing the original checkpoint directory, preventing same-second hard Stop/Resume websocket hangs.
- `workflows/semantic_tree_calibration_allmodels_M5.json`: configure the full labeled pool, six debate rounds, eight critic questions, and explicit deterministic frozen holdout evaluation.
- `docs/calibration_prompt_distillation.md`: record the corrected live run, held-out metrics, supported conclusion, and remaining semantic-rule limitation.
- Tests: cover multi-state cycles, video attachment, score-only comparison, cache behavior, and immediate same-second resume identity.

## Design decisions
Raw human ratings remain unreduced but each video has equal total weight. Global bias, score-only linear calibration, and score-plus-rule models are evaluated separately so the system cannot credit semantic rules for a gain caused by fitting the raw-score slope. Rule candidates remain training-only and critic features remain deployment-available. A result is called meaningful only when held-out MAE improves by at least 0.05 and the item-grouped bootstrap interval excludes zero.

- Best score-plus-rule linear MAE 1.107; incremental rule gain 0.006 with 95% CI `[-0.031, 0.042]`, correctly reported as indistinguishable from score-only calibration.

## Follow-ups
Semantic rules did not significantly improve over score-only calibration on seven validation videos. A larger and more diverse independently labeled validation set is still needed to assess incremental semantic generalization reliably.
