## Design decisions

reference-label changes or production gate changes. A correct expert's existence
is reported as oracle headroom, not a deployable router or causal attribution.

Six source/edit pairs were inspected as targeted examples. For the doodle case,
an isolated copy corrects the observer's missing-cat judgments and associated
materiality/consistency interpretation; all original files remain unchanged.
This is a diagnostic intervention, not a new model draw or official gold evidence.
No global causal error percentages are claimed from these few reviewed cases.
