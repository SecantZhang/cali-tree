## Design decisions

The final resolver is target-blind: initial rubric, matched-budget global TextGrad, and an
independent critic vote; a strict majority wins and a total three-way disagreement maps to
`partial`. Editor priors use only the official training partition and activate only with at
least 20 observations and a 70% majority. This recovered ordinary held-out accuracy while
retaining substantially better minority recall than the critic-only resolver.

All reported confidence intervals resample complete task UIDs so editor outputs from one
task never cross bootstrap units. Accuracy is also stratified by whether the three human SC
ratings are unanimous or disputed.

The seed-44 10% subset became a development set because aggregate results were inspected
while selecting consensus and prior behavior. It is therefore suitable evidence that the
pipeline works and that the approach is promising, but a separate frozen seed or the
remaining public test cases is still required for an untouched publication claim.
