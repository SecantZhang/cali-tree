# 261014-10:18:15 — Benchmark GPT-6 Luna and GPT-5.4 mini on the fixed AURORA groups

## Motivation
The user asked to try the current pipeline with small, fast models such as GPT-6 Luna and report accuracy. The user separately approved GPT-5.4 mini after automatic approval review rejected its initial addition. The rejected launch made no API calls.

## Changes
- Added an explicit-model, frozen-protocol collector for the exact previous 48 source-distinct AURORA cases: same prompts/schema, reasoning none, temperature 0, source-first, one HTTP attempt per arm/case, eight shared workers. Model lists are sealed and cannot change on resume. Defaults to Luna.
- Added offline shared/clustered v6 refitting per twelve-case group, frozen Sol shared-rule controls, paired common-resolved metrics, latency/token/cost summaries, content-addressed policy artifacts and independent request/metric audits.
- Added a separate post-hoc literal-quote normalization diagnostic. Only decorative outer quotation marks around an exact instruction span can be removed; no evidence facts/grades/labels change. Raw and strict results are preserved.
- Added five offline unit tests and repository docs/replay commands. Production defaults and historical experiments are unchanged.

## Design decisions
Both approved fast models produce their own new visual observations. No Sol evidence is reused for their local fits. The score rule family, four-term budget including offsets/visibility label, two shared cuts and two-correct-source class floor remain unchanged. Flat judgments are a separate matched control. The optional format correction is reported separately from the strict predeclared pipeline and does not require model calls. Invalid ellipsis/paraphrased spans remain invalid. Unresolved/model/validation failures stay in all denominators; an infeasible group is twelve explicit abstentions rather than a weakened class floor.
