# 261021-00:37:30 — Add portable forest and boundary-policy freezing

## Motivation

Make the selected matched-editor policy executable and inspectable without
depending on an in-memory sklearn model or refitting during later evaluation.

## Changes

- `critical/core/calibration/semantic_policy_v59.py`: closed-vocabulary JSON
  forest/three-boundary runtime with declared class ordering, weakest-boundary
  support, direct/available-expert modes, support gate and regular fallback.
- `run/freeze_calitree_matched_policy_v59.py`: requires the independent v58
  audit, fits its selected full-data configuration and verifies every one of
  915 pool predictions/supports before saving an optional research artifact.
- Tests cover both model exports, unavailable labels, support thresholds,
  exact ties, missing evidence, artifact hashes and undeclared input rejection.
- Coverage documentation describes the frozen inference check.

## Design decisions

The artifact contains semantic model structure and frozen expert runtimes;
fitting provenance remains outside the inference artifact. No source/case/editor
ID, image hash or raw language is accepted as a predictor. Boundary negative
support uses the positive-class complement, matching the fitted implementation.
Direct mode has no confidence gate. Supports are not calibrated probabilities.
Serving defaults and the old v49 artifact remain unchanged.
