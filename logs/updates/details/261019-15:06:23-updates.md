## Design decisions

The baseline deploys 4/4/2 experts, including overlapping scopes. Pair unions are
deduplicated, with every child's full local floor and each original batch retained.
Sharing counts only correctly predicted examples from multiple batches in the same
terminal rule, never mere mixed-batch membership.

Initial locally compact candidates exposed new acceptances after expert removal. The
first pilot rejected them. A bounded rejection-only distillation now preserves the
frozen system's abstentions using up to three literals per clause. It cannot repair
lost coverage or changed protected verdicts; those candidates remain rejected. This
fits to known routing decisions, so the regression probes are not held-out evidence.

The first full draft prioritized stored condition counts before sharing at equal tree
size. The final ranking follows the user's explicit preference: expert count, terminal
rules, shared correct support, balanced support, then stored condition occurrences.
The draft and its source snapshots remain recorded; the final run is r1.
