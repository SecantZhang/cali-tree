# 260727-23:11:56 — Add Cali-Tree PyCharm compound launcher

## Motivation

Make the Cali-Tree worktree directly runnable from PyCharm with the same compound
backend/frontend workflow used by the prompt-calibration worktree.

## Changes

- `.idea/modules.xml`, `.idea/calitree-implementation.iml`, `.idea/vcs.xml`: added local
  PyCharm project/module metadata for the `calitree-implementation` worktree.
- `.idea/runConfigurations/Cali_Tree_Interface_Server*.xml`: added normal and reload-enabled
  FastAPI launchers on port 8020 using the existing `Python 3.9 (vejudge)` SDK.
- `.idea/runConfigurations/Cali_Tree_Web_Dev_Server.xml`: added the Vite launcher on port
  5193, connected to the backend at `http://127.0.0.1:8020`, with browser auto-open.
- `.idea/runConfigurations/Cali_Tree_Full_Stack__Backend___Frontend_.xml`: added a compound
  launcher that starts the reload backend and Vite frontend together.
- The backend configurations explicitly resolve the shared `.env-raw` and downloaded
  ImagenHub corpus from the main VEJudge checkout.

## Design decisions

Ports 8020 and 5193 are intentionally distinct from the other worktree's 8010 and 5183, so
both IDE projects can run concurrently. The `.idea` directory remains local and ignored,
matching the repository and sibling-worktree convention; this update log is versioned.
