# 260923-20:00:01 — Audit condition-tree assumptions on ten AURORA cases

## Motivation

The user asked to test the necessary assumptions behind decomposing optimized
judge prompts, generalizing their conditions, and learning a transferable tree.

## Changes

- Added `run/assumptions_pilot.py`: metadata-frozen selection of ten task groups,
  replay of existing real repeated judgments, per-leaf stability, distribution
  fidelity, feature collisions, grouped tree fitting, task-bootstrap intervals,
  image extraction, provenance, and Markdown/HTML reporting. It makes no API calls.
- Added the versioned assumption report and unblinded assistant image/text audit
  under `docs/experiments/`.
- Added three statistical validation tests under `tests/unit/experiments/`.
- Saved all per-case records, fold trees, image pairs, hashes, and reports under
  `logs/exps/260923-20:00:01-exps/`.

## Design decisions

- Reused ten independent recorded repetitions from each existing ablation arm,
  avoiding provider drift and new API charges. These are historical results, not
  fresh official-API judgments. Never use confirmation repeats conditional on
  a successful search gate.
- Selected 3 no / 4 partial / 3 yes cases across eight source categories and five
  editors. The cohort is explicitly selected from prior prompt-repair cases.
- Kept every task's repeats in the same train/test fold. Used fixed depth-2 trees
  and at least 20 training records per leaf, which entails at least two task groups.
- Distinguished structured rubric execution from independent instruction-derived
  conditions; the latter do not claim to preserve the former's policy.
- Downloaded the public AURORA archive into the task-owned temporary file and
  verified its pinned digest. Extracted only the 20 selected images into the run.
- Reported assistant visual inspection as unblinded, non-human evidence; did not
  invent human concept annotations or an oracle-feature evaluation.

## Follow-ups

- Human concept labels, repeated decomposition stability, and a truly independent
  task/domain test remain required. Ten selected tasks do not establish generality.
- Current predicates omit count/identity distinctions and compress preservation
  too aggressively; revise those definitions before a larger experiment.
