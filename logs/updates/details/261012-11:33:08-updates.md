all twelve selected leaves qualified. Six merged criteria and seven instruction scopes
were constructed. Parent fitting evidence scored 8/12; separate selection scored 5/12.

On twelve held-out sources, majority accuracy was 8/12 (66.7%) for the fresh Luna baseline,
4/12 (33.3%) for the frozen Sol CaliTree parent, and 7/12 (58.3%) for the fixed readout

20/60. Partial recall improved 25% to 75%, but yes recall collapsed 100% to zero and no
recall declined 75% to 25%. The selected tree has no yes terminal label. Eleven test cases
use shared criteria; only one reuses specialization. The parent should not be promoted.
