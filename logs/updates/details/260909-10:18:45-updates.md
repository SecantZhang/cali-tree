# 260909-10:18:45 — Add reproducible AURORA-Bench calibration dataset

## Motivation

Prepare AURORA-Bench for a quick image-LLM judge calibration experiment on the human
`0=none`, `1=partial`, `2=full` scale, without adding frontend work.

## Changes

- `run/setup_aurora_bench.py` / `.sh`: added resumable download of the official ratings JSON
  and image ZIP, pinned SHA-256 validation, safe extraction, asset validation, deterministic
  task-grouped splits for seeds 42/43/44, and a per-file provenance manifest.
- `vejudge/database/dl_aurora`: added a read-only `DataLoader` implementation for filtering
  the five models/eight task types and emitting judge-ready source/edited image pairs.
- `vejudge/config.py`: added `VEJUDGE_AURORA_BENCH_ROOT` with the standard data-root default.
- `tests/unit/database`: added score-boundary, grouped-split, archive-safety, manifest, loader,
  and incomplete-setup coverage.
- `docs/calitree.md`, `docs/data.md`, `run/README.md`: documented setup, score provenance,
  grouped splits, and use of the continuous versus binned targets.
- Materialized the complete release under `.claude/data/aurora/bench`: 2,000 outputs from
  400 source-prompt tasks and five models (466 MB after removing the downloaded ZIP).

## Design decisions

The public artifact exposes only an aggregate human mean on `[0,2]`, although the original
choices were none/partial/full. The loader therefore preserves `human_score` as the primary
target and does not invent per-rater observations. Existing three-class experiments can use
the preregistered half-point mapping `<0.5=no`, `[0.5,1.5)=partial`, `>=1.5=yes`. Splitting is
by source-image/instruction task, keeping all five model outputs together to prevent leakage.
The integration is dataset-only; no interface source node or frontend changes were retained.

## Follow-ups

Use the continuous aggregate score for regression/calibration metrics and the fixed class view
only when directly comparing with ImagenHub's three-class experiments. Raw AURORA ratings are
not public, so inter-rater calibration/ceiling analysis is unavailable from this release.
