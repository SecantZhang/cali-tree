## Design decisions

- Re-run mini on the official API because the previous pilot used a historical proxy.
- Primary comparison: same prompts/images, temperature 0.3, reasoning none, output
  cap and fixed aggregation. Luna medium direct is a separate exploratory arm;
  temperature is omitted for API compatibility and the token cap is larger.
- Cross both evaluators with historical and one newly generated Luna instruction
  decomposition per case. Preserve the existing decomposition prompt and first
  generated plan. This is not the full optimized-prompt compiler proposed in research.
- Share preservation results across the two decomposition arms within model/repeat.
- Never select or regenerate a completed model output based on correctness. All
  completed results, even invalid ones, checkpoint; only transport failures retry.
- Accumulated list-price stopping threshold $15; realized estimate $0.9180752.
  In-flight/failed-request billing is not established by this estimate.
- No application provider behavior or unrelated dirty files were modified.
