# 261014-10:37:55 — Instruction-dependent noncompensatory rules and frozen cross-group tests

## Motivation
The user requested implementation and testing of instruction-dependent rules with explicit interactions after identifying evidence omission, compensation and underdetermination in weighted score formulas. The decisive requested validation freezes a policy on one group and applies it to other groups without recalibration.

## Changes
- Added `InstructionRuleCalibrator`, an opt-in `Calibrator` subclass using instruction-contract flags and anonymous applicable/grade facts. No weighted sum, IDs, words, hashes or reference lookups enter prediction.
- Yes requires progress AND endpoint AND every instruction-required fidelity check AND applicable preservation. Identity, relations and quantity activate from the instruction; attribute/scope gates use the contract and applicability. A required check cannot be traded against scope or another strong dimension.
- All candidates forbid Yes when any active required check has a material grade <=2. Clearly wrong required identity / destroyed source meaning yield No. Meaningful progress with material shortfall yields Partial. Missing/contradictory applicability is interval-valued unknown, with no learned uninspectable-to-No shortcut.
- Four thresholds, sixteen fixed candidates; joint accuracy/macro-F1 objective, two correct sources per class, deterministic default-biased tie-breaking, training-equivalent-policy diagnostics and serializable rule artifacts. Gates cannot be deleted or weakened by optimization.
- Added cached same-evidence local and frozen train-12/evaluate-other-36 runner; primary Luna G1 -> G2/G3/G4, all four reciprocal folds and Sol/previously normalized-mini secondary runs. Frozen old v6, same-model flat and fixed unfitted semantic controls are separate arms. Training artefacts publish before test scoring.
- Added independent direct-rule and metric audit/report, twelve meaningful offline unit/property tests, docs and replay commands. Earlier code/prompts/caches and production defaults are untouched.

## Design decisions
This isolates decision logic from extraction by reusing exactly the same 48 cases, labels and same-model observations. Mini uses only the six already verified literal quote repairs. The grade scale already defines 2 as a material shortfall and 3 as near-complete; the candidate family respects those semantics. Failed fits are explicit abstentions rather than relaxing the class floor. A fixed semantic default is an independently named no-label control, never a silent fallback. All four groups have been examined historically, so cross-group evaluation holds out labels from each fit but is retrospective method development, not a pristine unseen test.

## Results
The intended logical guarantees pass, but this prototype is NOT an accuracy upgrade.
- Fixed, unfitted semantic defaults: Luna 27/48, Sol 26/48, mini 21/48. Their flat controls are 31/48, 30/48, 24/48 respectively.
- Qualified learned fits: Luna 2/4 groups (G2/G3), Sol 3/4 (G2/G3/G4), mini 2/4 (G1/G3). Counting unsupported groups as twelve abstentions gives local pipeline counts 19/48, 25/48, 15/48 respectively; prior locally fitted v6 counts were 39/48, 42/48, 34/48.
- Predeclared primary Luna G1 trained fit has zero supported candidates. No qualified G1-trained v7 deployment was selected. Frozen prior G1 v6 gets 19/36 elsewhere, flat 22/36, predeclared fixed semantic default 22/36.
- Luna qualified G2/G3 fits score 10/12 and 9/12 locally, then 15/36 and 18/36 on other groups versus prior frozen v6 15/36 and 15/36. This is not sufficient for a broad transfer-improvement claim. All 12 train-group fits/36 off-diagonal model/group cells are in report/results.
- One real compensation fix: Sol G4C02 (pour into pot), old local Yes -> new fixed Partial, matching the reference. But six human-Yes Sol cases are also blocked. Cached evidence sometimes gives human-Yes cases low identity or endpoint grades; stronger gates faithfully expose rather than repair those disagreements.
- Zero new API calls / zero new API cost. No retries, case replacement, label changes or model mixing.

## Follow-ups
Keep v7 experimental. Cached grades and human references disagree on materiality, and the stricter gates reduce recall. Further work should validate instruction-relative evidence, distinguish physical endpoint from identity penalties, and freeze a revised method before testing on fresh sources. Do not promote this prototype based on passing logical tests or occasional transfer gains.
