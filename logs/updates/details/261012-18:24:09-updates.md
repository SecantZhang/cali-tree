# 261012-18:24:09 — Check-level optimization and matched AURORA pilot

## Motivation

Implement check-level supervision, switch back from EditReward to the original twelve
AURORA cases at the user's request, and run a parallel comparison with the v2 optimizer.

## Changes

- Added check-target, check-evaluator and check-optimizer contracts; label-blind paired
  provisional target collection, target coverage tracking, contrast-supervised condition
  repair, protected contracts/weights, frozen selection and independent final evaluation.
- Added a default AURORA runner with matched fresh v2 and source-control arms. Preserve
  all twelve cases, including historically unverified leaves, and exclude the reserved
  H01–H50 cohort. Added frozen snapshots, bounded per-arm ledgers, four-worker execution,
  verifier, offline replay and reports; retained explicit EditReward import compatibility.
- Documented the reference policy, compound-check limitation and differing acceptance gates.
- Corrected a v1 acceptance bug after the pilot: infrastructure-only baseline deficits
  cannot trigger semantic repair or justify acceptance in v1.1. Added exact regression
  tests and protocol mismatch protection. No frozen live source was rewritten.

## Design decisions

Use two independent requests to the same Sol family (medium/high effort) as provisional
check references; never call them human ground truth. Disputed targets remain unverified.
Use original plus two alternatives for development and reserve the other two from the
optimizer. Preserve dataset labels for reporting only. Target agreement, check qualification,
overall labels and merge eligibility are reported separately. No merge is run.

## Verification

- Before live: 1,565 unit tests passed, 23 skipped. Final post-fix suite: 1,567 passed,
  23 skipped, 52 warnings; focused suite 57 passed; final check-study tests 15 passed.
- Completed all twelve AURORA cases across both live arms: 818 cumulative calls,
  27 retained transport failures and three retained interruptions, within 3,840 calls.
- Recovered from a transport stop via three healthy credential-free probes, an audited
  copy and offline replay-to-next-slot tests; continued at two parallel workers. All
  693 inherited jobs and eight completed cases stayed byte-identical; zero duplicate slots.
- Verified 216 whole-leaf traces, 121 v2 traces, 183 training-check observations/metrics,
  and 70 target records. Frozen offline replay passed with zero new calls.
- Both methods scored 10/12 original case majorities. Check agreement on reserved
  alternatives was 17/23 versus v2's 16/23, with the difference on an unchanged program.
- The sole accepted revision lacked valid semantic-improvement evidence because its
  baseline deficit was a transport error. Preserve the raw result and flag it post hoc.
- No check-level EditReward live calls, reserved-holdout calls, or merge were performed.
