## Design decisions

The unchanged276-case/84-source evaluation excludes all siblings of each held
source. In v61, all router-training base predictions are additionally source-held
within the allowed fitting pool. Protected examples are supervised training data,
not an inference membership test. Model support and language mentions are not
factual or calibrated confidence claims.

The new ordinal objectives use unchanged reference bins. Within-task centering
uses ONLY supplied fitting labels on complete five-editor groups. The frozen
vision model uses the current input's target text to compute relative scores;
only reusable scalar thresholds reach the policy. Sources and labels remain
outside inference. The official AURORA rubric was rechecked as semantic editing
success, not a replacement target based on image aesthetics.

Dependencies live under `/tmp/calitree-catboost-v62` and
`/tmp/calitree-vision-v63`, leaving the shared project environment unchanged.
The initial sandboxed vision launch could not access Metal and failed before
creating encoder state; the same frozen code then ran with GPU access and
network disabled. No transport/model API budget was used.
