# 261013-23:21:51 — Correct three-label calibration and uncertainty handling

## Motivation

The user asked to fix the overly restrictive local calibration layer after its
same-36 recalibration could not improve beyond 20/36. The restrictions froze No
decisions, prohibited learned No leaves and indiscriminately blocked unknowns.

## Changes

- `critical/core/calibration/evidence_rules_v3.py`: new Calibrator subclass with
  No/Partial/Yes leaves, learned target/source inputs, anonymous minimum/maximum
  core progress, conservative evidence intervals, definite-source leaf support,
  vectorized exhaustive monotone search and portable restore.
- `run/calitree_recalibrate.py`: corrected offline preflight/fit/replay entry point
  for the exact 36 cached records; immutable registry and previous/flat comparison.
- `tests/unit/calitree/test_evidence_rules_v3.py`: all-three-label learning,
  formerly fixed-No changes, relevance-based uncertainty, monotonicity, metadata
  exclusion, bounds, invariance and artifact tests without paid calls.
- `docs/calitree_evidence_rules_v3.md`, `run/README.md`: corrected contract, usage
  and explicit historical-runner compatibility.
- `logs/exps/261013-corrected-local-calibration-v3/`: frozen inputs/code, new policy,
  local metrics/report, exact replay, actual-record constraint audit and analysis.

## Design decisions

No immutable label guards. Unknown observations define feasible lower/upper
feature summaries, not imputed facts. Since all policies are monotone, agreeing
endpoint labels prove every completion has one label; disagreement remains
unresolved. Support counts only sources guaranteed to reach each leaf.

Retain depth two, max three split nodes, at least two distinct source cases per
leaf, categorical anonymous predicates, monotonicity and full-evidence Yes. Add
target correspondence and any-core progress from existing cached fields. No new
image/model calls, ID/object/text/count predicates or case-specific exceptions.
Old v1/v2 contracts, frozen benchmark and canonical fulfillment optimizer remain
unchanged. The new CLI is the corrected opt-in local calibration path.
