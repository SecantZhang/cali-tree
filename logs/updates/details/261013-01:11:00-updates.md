## Design decisions
Sample four rows per mean-derived class from the prepared training partition,
seed 42, without looking at predictions or substituting difficult cases. Twelve
source-pixel groups, one AURORA edited output each, seven task categories. The
full 400-row corpus remains in the manifest and the 322 test rows stay unqueried.
All stages use the same gpt-6-luna settings; baseline and distinct candidate checks
execute once, without teacher consensus or confirmation resampling. One sparse
candidate per row; no merging or shared-parent test phase in this current leaf study.

The first frozen startup attempt used the snapshot directory for .env resolution
and made zero API calls. Its preparation and run.log remain in
logs/exps/261013-aurora-single-output-balanced12/. After the code fix a new live
directory was prepared and verified to contain exactly the same frozen sample.
Actual repository credentials stay external to the pinned source snapshot.
