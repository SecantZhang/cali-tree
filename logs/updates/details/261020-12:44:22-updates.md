## Design decisions
The first authorized collector attempt reserved three compiler slots but failed
inside chat_request before HTTP dispatch. No model response existed. Those failed
artifacts remain intact in the prepared directory. The corrected copy uses the
existing Luna serializer default, which still emits the explicitly approved
reasoning_effort=none. Original frozen code and preflight artifacts were not edited.

The new run copies the same cohort/gates and subtracts all three local attempts
and 24,576 reserved completion tokens from its budget, leaving 269 requests and
2,367,488 completion tokens. The user had already authorized the run and routine
adapter repair; no additional paid scope or resampling was introduced.

Two regular-judge requests and one observation request failed at the transport
layer. They were retained without retries or replacement. Failed regular results
count unresolved; failed extraction uses its regular response. The primary
comparison retains all 80 outputs; a secondary comparison uses the 77 cases with
both successful regular judgment and extraction.
