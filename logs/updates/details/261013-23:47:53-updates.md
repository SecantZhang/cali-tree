# 261013-23:47:53 — Class-balanced objective prevents Partial collapse

## Motivation

The user asked why Partial recall was zero and requested an objective that learns
all three labels, followed by local recalibration/testing on the same 36 cases.
The v3 accuracy objective had selected a No/Yes-only policy with 22 matches.

## Changes

- `critical/core/calibration/evidence_rules_v4.py`: versioned subclass reusing v3
  evidence/rule/uncertainty semantics, replacing total-correct selection with exact
  macro-F1 and at least two correct distinct source cases per class. Ties favor
  worst-class recall, total correct, simplicity and fixed reference proximity.
  No collapsed fallback is permitted.
- `run/calitree_recalibrate_balanced.py`: offline frozen same-36 fit/replay with
  v2/v3/flat comparisons, per-class F1/recall, immutable policy artifact and cache pins.
- `tests/unit/calitree/test_evidence_rules_v4.py`: objective/class-collapse
  regression, unresolved FN accounting, all-class learning, infeasible-class
  refusal, uncertainty, restore and metadata/identity isolation.
- `docs/calitree_evidence_rules_v4.md`, `run/README.md`: objective and usage.
- `logs/exps/261013-class-balanced-local-calibration-v4/`: frozen objective/code,
  policy/results/report, exact replay, controlled-comparison audit and analysis.

## Design decisions

Keep evidence, labels, seven features, eleven predicates, depth two/three splits,
two-source leaf support, 972-point monotonicity and v3 uncertainty handling fixed.
No new checks, image/model calls, case-specific rules or lookup vocabulary.
Macro-F1 balances class-level precision/recall; unresolved cases remain FN. The
per-class floor rejects unsupported class abandonment without forcing labels or
altering observations. Fail explicitly if no eligible policy exists.

## Verification

- Nine-file targeted offline suite: **120 passed**, no paid APIs.
- V4 local accuracy **21/36 (58.3%)**, macro-F1 **0.608**, versus v3 **22/36
  (61.1%)**, macro-F1 **0.492**. One raw match is traded for class balance.
- Correct No/Partial/Yes **5/12, 7/12, 9/12**; Partial recall rises 0→58.3%,
  worst-class recall 0→41.7%. Resolved 33/36; unknown E03/E07/E26 retained.
- Winning policy recognizes all classes above the two-case floor; the floor is
  nonbinding at optimum. Same best macro-F1 without floor: 0.608.
- Same 42,969 candidates, 6,357 supported, 473 supported+monotone, 188 additionally
  class-supported. Four learned leaves contain 12/9/6/6 distinct definite sources.
- Feature/target hashes and grammar match v3 exactly. Actual-cache audit: 144
  invariant transformations, 972 points/4,050 edges, class-support proof.
- Exact refit/replay matches; previous results unchanged; **zero API calls**.
  Compile and whitespace checks passed. Canonical optimizer remains unchanged.

## Follow-ups

This fixes local class collapse under the optimization objective. It does not
solve overall calibration: flat remains 25/36 with macro-F1 0.706, and label/evidence
conflicts persist. Same-case metrics are not held-out accuracy or repeat robustness.
No objective switching after v4 results or optimizer-goal resumption is performed.
