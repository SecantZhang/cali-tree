## Design decisions

Rubric-Lite deliberately uses one prompt and one image-judge call per case. It has no
embeddings, task leaves, semantic merges, routing thresholds, critic ensemble, or editor
prior. Candidate prompts are selected only on a task-disjoint training validation slice,
with a one-point maximum accuracy regression guard and partial F1 as the secondary objective.
The 50% confirmation was not run because neither frozen 10% version met the stated overall
accuracy and partial-F1 promotion criteria.
