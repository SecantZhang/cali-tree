# 260721-15:57:14 — Stabilize semantic calibration and held-out evaluation

## Motivation
The latest calibration run had constant base scores, only nine independent videos despite 126 raw ratings, nearly constant semantic features, label-grounded transcript leakage into tree construction, an oscillating 11-round polarized debate, and a negligible tree-versus-bias gain that was reported too optimistically.

## Changes
- Calibration fitting: raw ratings remain separate but sum to one training-weight unit per video; linear, CART, semantic-tree, bias, item-macro metrics, and grouped validation now honor those weights. Calibrator versions were bumped.
- Evaluation: new rule/semantic tree nodes default to deterministic frozen holdout, while legacy graphs retain explicitly exploratory grouped LOO. Rule banks are mined only from validated training semantic summaries, constant training questions are dropped, and semantic-tree features are restricted to raw judge scores plus target-blind critic answers.
- Diagnostics/verdicts: reports now expose videos versus ratings, score provenance, aligned-label skips, base-score variance, split membership, feature prevalence, weighted/macro MAE, warnings, and paired bootstrap uncertainty. A positive verdict requires at least five validation videos, 0.05 MAE improvement, and a 95% interval above zero.
- Negotiation: raw ratings become one immutable disagreement profile; both debate prompts were versioned, rounds are capped at six, repeated semantics and A-B-A-B score cycles stop early, and oscillation retains the original score. Debate/summary checkpoint keys include the new versions.
- Interface and documentation: added split controls, disagreement/provenance details, calibration warnings, dropped-feature details, and honest held-out labels.

## Design decisions
Human labels remain available to the training-side adversarial critic, but no held-out label-grounded transcript field is a deployable tree feature. Raw annotations are not aggregated; weighting only prevents videos with more annotators from dominating. A frozen model remains trained on the training partition after evaluation rather than being silently refit on validation labels. Legacy nodes without the new mode preserve their prior call behavior but cannot make a generalization claim.

Meaningful performance claims still require a larger and more diverse labeled sample. With fewer than 20 training videos or five validation videos, the system now reports the result as exploratory/insufficient rather than treating the warning as a model improvement.
