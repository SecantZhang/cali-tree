## Design decisions

One GPT-6.1 Sol/high response per original SOURCE-first image pair, with four API
workers and no retries/repeats/reviewer model. Extraction finishes before the
runner passes human labels to calibration. The schema is informed by prior
inspected errors, so label-blind extraction is not claimed to be blind study design.

Rules remain categorical and anonymous: no object names, IDs, instruction matches,
text vocabulary, task categories or exact counts. Appearance drift differs from
entity/relation changes; visibility is factual, not a mandatory crop penalty.
The old frozen policy and old refitted grammar on identical fresh base fields
control for observation changes. The previous caches and default optimizer are
not altered.
