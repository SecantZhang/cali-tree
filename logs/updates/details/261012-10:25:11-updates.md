## Design decisions

The reserved test requires at least 46/50 correct parent-majority predictions from three fresh draws per case. A software test, an oracle representation bound or a development result does not meet this requirement.

Criterion identity is a semantic measurement context: a generic placement question and a strict original-target relocation criterion need not have comparable score distributions. It is not a per-case label lookup. Optional configuration preserves legacy execution. Existing default fulfillment arithmetic remains unchanged.

The final verifier independently derives features and traverses stored branches instead of using production prediction methods. It verifies model/template/schema/media/slot hashes against durable jobs. Reference labels enter only post-execution metric calculations. Supporting observations never become additional completed edits.
