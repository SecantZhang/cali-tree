## Design decisions

All five repeats stay within source/instruction groups; each case has total weight one. Leaf support uses case mass and explicit distinct-case checks, including floating-point tolerance at exact support boundaries. Unknown and incomplete draws remain unresolved for all arms. No model engines or credentials are used by this runner.

The 31 historical cases have only one yes label. Two have no known draws. The 19 later cases have two yes labels and two entirely unresolved cases; primary conditional metrics use 17 cases and 75 known draws. Both cohorts were previously inspected, so the result is retrospective rather than untouched confirmation. Some historical criteria used label feedback; later criteria did not.
