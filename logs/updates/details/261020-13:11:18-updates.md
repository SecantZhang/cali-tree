## Design decisions
One vote per distinct expert tree, unweighted by support or number of regions.
Plurality wins; among tied winners prefer Partial, otherwise No for a No/Yes tie.
All task/region/support/counterexample/disagreement gates are bypassed. Evidence
validation remains required. Failed extraction yields unresolved rather than
regular fallback; all 80 cases remain in the denominator.

The protocol was frozen before this ablation scored votes. Prior pilot outcomes
were already examined, so this remains an exploratory development ablation. No
alternative vote/tie rule was selected after scoring. Original models, prompts,
labels, cached evidence and paid-call ledger remain unchanged.

The first draft audit found integer-key versus JSON-string-key serialization in
the prediction-count summary. This was fixed without altering votes or protocol;
the draft/source snapshot remain. Final sealed run is
`logs/exps/261020-ungated-ablation-v30-r1`.
