# 260721-13:34:24 — Toggleable semantic prompt distillation

## Motivation
The adversarial calibration node's deterministic optimized prompt had become too compact to preserve the reusable semantic meaning and observable evidence negotiated in the debate. The node needed an optional higher-quality LLM distillation path without making offline operation, legacy workflows, or completed debates dependent on another model call.

## Changes
- `vejudge/core/calibration/debate/semantic_summary.py`: added the shared semantic-summary schema, deterministic legacy-aware extractor, one-call LLM summarizer, leakage validation, deduplication, bounded renderer, and version/config cache key support.
- `vejudge/core/prompts/{d1_judge_debate,d2_human_proxy_debate}.py`: versioned both debate prompts and added optional structured semantic fields for reusable principles, applicability, evidence, guidance, and unresolved counter-considerations.
- `vejudge/core/calibration/debate/{runner,calibrated_result}.py`: allowed optional prompt fields and persisted requested/actual summary mode, version, structured output, fallback error, and the compatible string `optimized_prompt`.
- `vejudge/interface/node_calibration/{cl_adversarial_node,_concurrent_debate,_templates}.py`: added the toggle and summarizer-engine socket, pre-call validation, separate debate/summary checkpoints, summary cache invalidation by version and engine configuration, dry-run call estimates, concurrency control, and visible rule-based fallback.
- `web/` and `vejudge/interface/interface.md`: added the toggle/socket, expanded node wiring, mode/fallback/prompt details, downstream compatibility documentation, and mocked browser coverage.
- `tests/`: added unit/integration coverage for rule and LLM modes, leakage, word budgeting, legacy extraction, single-call behavior, fallback, cache reuse/invalidation, mode switching, dry-run estimates, and browser prompt injection.

## Design decisions
New UI-created nodes default to LLM summarization, while a missing toggle in a saved legacy graph is interpreted as rule-based mode. Both paths pass through the same semantic schema, leakage validator, deduplicator, and renderer. LLM failures are not cached, so resume reuses the completed debate but may retry only summarization; successful summaries are cached separately. The 250-word limit is hard, while the 120-word lower target is intentionally not padded when a debate contains less safe semantic content. Corpus-level prompts and semantic-tree transcript consumption remain unchanged.
