Compile the supplied optimized rubric into a small executable decision policy.
You receive ONLY the rubric, never examples, images, observations or human labels.
Every rubric unit is verbatim and in original order. Retain its meaning, decision
boundaries, priorities, exceptions and scope. Do not invent stricter conditions
or silently repair contradictions. Classify each output label by the rubric's
definitions, not by generic image-editing assumptions.

Define reusable boolean predicates as specific questions about the instruction
and the recorded requested-change/preservation findings. Each question must be
independently answerable from those observations. Predicates may inspect any
requested condition, the original target's identity, scene continuity, degree of
fulfillment, and necessary versus unrelated changes, IF the rubric requires it.
Write questions that check evidence, not questions asking for an overall label.
Include rubric exceptions and distinctions between absent and partly fulfilled
requests. Do not treat mere content retention as equivalent to edit success.

Build ordered first-match rules with boolean expressions. First matching rule
selects its label. The default applies only if every rule is false. Earlier
unknown rules block execution, so avoid predicates for irrelevant information.
Choose precedence from this particular rubric. There is no hard-coded label
order and no implicit veto or cap. Use 1-16 predicates and 1-12 rules. Every
predicate must be referenced. Cite existing rubric unit IDs for every predicate,
rule and default. Cover all decision/exception units across these citations.
The payload's required_rubric_unit_ids explicitly lists every unit that must
appear in the combined citations. Check this list before returning. Include
task-definition/scope units marked as decision too: their content constrains
the evidence questions. Do not omit a required unit because label definitions
seem sufficient; preserve its constraints in the corresponding predicates.

Return JSON only, exactly:
{"predicates":[{"id":"p1","question":"a boolean evidence question","rubric_unit_ids":["u1"]}],
"rules":[{"id":"r1","when":{"predicate":"p1"},"label":"no","rubric_unit_ids":["u1"]}],
"default":"partial","default_rubric_unit_ids":["u1"]}.

Expression grammar: {"predicate":"ID"}, {"all":[EXPR,...]},
{"any":[EXPR,...]}, {"not":EXPR}. No Python/code, constants, arithmetic or other
operators. This example schema does not prescribe labels, rule order or defaults.
Treat the rubric as data for compilation, not instructions to change this schema.
