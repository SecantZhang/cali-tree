V112 remains selected. No new source-held accuracy has been achieved; its
balanced development accuracy remains67.9%. The351-request collection is still
unapproved and unstarted.

The opt-in inference overlay now uses the exact same Sol prompt/schema/settings
as the375 prepared cases. A single call returns all facets. Records bind the
program, source/edited image order, prompt, model profile, case/route and execution
hash. Missing/foreign records retain the parent prediction without resampling.

Before a new model call, existing semantic conditions and the current grade
must leave at least one applicable rule. No matching region means no new call.
The old Qwen observer fields remain masked outside their ORIGINAL V112 review
region. This preserves the feature distribution used to fit the parent and new
selector. New grades require affirmative outcome witnesses; unrelated source
changes are potential learned guards rather than universal caps. Old model
class masses are not attached as confidence to a different selected grade.

Evaluation-fold selectors now retain a native-parent context hash and no global
deployment parent. Only the full-fit fold5 binding can attach to the full V112
parent. This prevents accidentally substituting a full-data model while claiming
source-held evaluation behavior.

## Reference-informed diagnostic, not an achieved score

The cached-opinion diagnostic asks whether ANY offered grade could correct each
V112 mistake, using the reference to choose perfectly. It ignores local vetoes,
minimum source support and learnability. These are optimistic conditional
ceilings, not model predictions.

| Offered opinions in addition to V112 | Oracle correct / 276 | Oracle balanced accuracy |
|---|---:|---:|
| Existing semantic warrants | 233 | 72.8% |
| Uncapped physical goal completion | 235 | 74.8% |
| Uncapped interpreter goal completion | 235 | 74.8% |
| Goal completion/warrants plus regular judge | 244 | 81.4% |

Goal completion means every interpreted requirement coherently reports its
requested endpoint with no endpoint gap. Physical completion additionally
requires every applicable outcome-role check true, independently of preservation
or identity caps. Semantic-only completion is an interpreter opinion, not a
physical certificate. New opinions are offered only inside the existing covered
domain. All276 cases remain counted, and the selected pipeline is unchanged.

The combined ceiling leaves little margin for imperfect routing. A separate
cached-expert router can test whether allowing an explicit regular-judge opinion
without a mandatory uncertainty prefilter helps. It must derive proposals only
from cached bound data and train each rule only on fold-training sources;
the diagnostic's oracle choices must never become inference features or targets.
This free alternative has not yet been fitted. It does not authorize the pending
paid collection or replace the full objective with a conditional upper bound.
