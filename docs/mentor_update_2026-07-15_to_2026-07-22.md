# VEJudge Weekly Project Update

**Reporting period:** July 15–22, 2026

**Five-slide draft for mentor discussion**

## Slide 1 — Project overview

My project is to build a complete system for calibrating multimodal LLM/VLM judges that evaluate AI-generated video edits. The system covers data loading, judge execution, adversarial negotiation, semantic prompt distillation, ontology-guided decision-tree calibration, held-out evaluation, run management, and an interactive workflow interface.

### Progress this week

- Expanded from a small rule-tree prototype into an end-to-end calibration system.
- Increased the labeled calibration pool from **13 to 33 usable videos** across Peanut, Coconut, and Grapenut.
- Preserved individual human ratings and added statistically correct video-level weighting.
- Built interpretable semantic trees whose learned branches use editing evidence rather than raw-score shortcuts.
- Added reliable execution, checkpointing, experiment inspection, and workflow visualization.

**Takeaway:** The work now addresses the full calibration system—not only an isolated fitting pipeline.

## Slide 2 — Framework updates

- Split calibration into two reusable component families:

**Takeaway:** The framework now supports multiple data sources, calibration strategies, and evaluation tracks through one modular system.

## Slide 3 — Algorithm updates

### Adversarial negotiation and semantic distillation

- Added deterministic and LLM-based semantic summarization modes with a shared structured schema.
- Preserved reusable principles, applicability conditions, observable evidence, scoring guidance, and counter-considerations.
- Added strict filters for human-score, target-score, and correction-magnitude leakage.
- Stabilized negotiation with fixed human-disagreement profiles, semantic early stopping, cycle detection, and a six-round limit.
- Added video-grounded independent critics, retry handling, and graceful fallback for malformed model outputs.

### Calibration and evaluation

- Kept raw ratings as separate targets while weighting them so every video has equal total influence.
- Added deterministic frozen train/validation splits, item-macro MAE, grouped bootstrap confidence intervals, and training-only model selection.
- Separated improvement from global bias, score-only calibration, and incremental semantic-rule effects.
- Rebuilt the semantic tree around ontology-guided evidence:
  - prompt identity is a fixed router;
  - raw score and score variance are used only inside leaf models;
  - learned decision branches use rubric or debate semantics only.
- Added an exploratory deeper-tree mode while retaining the safer generalization-first model as the default.

**Takeaway:** The algorithm is now more stable, leakage-safe, interpretable, and statistically honest.

## Slide 4 — Pipeline, reliability, and interface updates

### Pipeline reliability

- Moved runs into dedicated worker processes so **Stop terminates local work immediately**.
- Preserved completed checkpoints and reran only interrupted or stale units on Resume.
- Separated debate and summarization caches to avoid repeating expensive model calls.
- Added disk-backed run reconstruction and a Runs browser for reopening or resuming experiments.
- Added no-call semantic rerendering so tree variants can reuse completed checkpoints.
- Fixed malformed critic JSON, literal JSON braces in custom prompts, and same-second Resume identity issues.

### Interface and observability

- Added generic Inputs, Outputs, and Timing tabs to every node.
- Added API-driven socket schemas, per-node timing, and a system execution waterfall.
- Added interactive SVG decision trees with semantic labels, tooltips, and aligned training/held-out metrics.
- Added one-click topological auto-layout for large workflows.
- Added diagnostics for score provenance, raw-rating counts, warnings, split membership, dropped features, disagreement, oscillation, and semantic split counts.

**Latest verification:** **469 backend tests, 132 frontend tests, and 35 Playwright browser tests** passed using local mock services.

## Slide 5 — Results, conclusions, and next steps

### Main results

| Experiment | Held-out result | Conclusion |
|---|---:|---|
| Corrected score-only calibration | MAE **1.114 vs 1.176** bias; gain 0.062; 95% CI [0.004, 0.150] | Supported improvement over global bias |
| Guarded graded semantic tree | MAE **1.062 vs 1.176** bias; gain 0.114; 95% CI [0.003, 0.206] | Semantic model improved over bias |
| Joint M3/M5/M6 linear semantic model | MAE **0.97 vs 1.19** bias; gain 0.22; 95% CI [0.06, 0.38] | Strongest overall calibration result |
| Incremental debate-rule signal | Gain **0.006** over score-only; 95% CI [-0.031, 0.042] | Not yet statistically distinguishable |
| Semantic-first tree | **3 semantic splits, 0 score splits**; MAE 1.008 | More interpretable and better than the prior semantic tree |
| Exploratory deeper tree | **5 semantic nodes, 4 questions**; MAE 1.017 | More training fit, but no held-out improvement |

### Conclusions and next steps

- The system now shows meaningful overall calibration improvement with leakage-safe held-out evaluation.
- Semantic branches are genuinely evidence-based, but their incremental predictive value is still uncertain.
- The current frozen validation set contains only **7 videos**, so stronger generalization claims would be premature.
- Next: expand and diversify labels, improve the distinctness of distilled semantic decisions, analyze critic-feature coverage, and compare against stronger state-of-the-art baselines.

**Takeaway:** The system is working and overall calibration improves, but more labeled validation data is required to prove that deeper debate-derived semantic rules generalize.
