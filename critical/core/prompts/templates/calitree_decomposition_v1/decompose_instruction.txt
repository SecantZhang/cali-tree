Compile the instruction into requested atomic conditions and permissions.
Return a JSON object with exactly edits, allow_identity_change, allow_background_change.
edits is an array of objects with exactly key, operator, expected. Each object
names ONE check. Valid key strings are color, shape, position, count. Never join
names with punctuation or copy a list of alternatives into a key.
Valid operator strings are equals, one_of, at_least; use exactly one per object.
For example a red-color condition is {"key":"color","operator":"equals","expected":"red"}.
A circular-shape condition is {"key":"shape","operator":"equals","expected":"circular"}.
Include only explicitly requested checks, once each. Exclude unrequested checks;
return an empty edits array if there are none. Preserve zero numeric requirements.
Color, shape and position expected values are strings. Normalize round/circle
shape to circular; normalize positions to left_of_reference or right_of_reference.
Count values are nonnegative integers, including zero: exactly N uses equals,
at least N uses at_least. Permitted color shades use one_of with the array
[color, 'light '+color, 'dark '+color]; otherwise use equals.
Permission fields are booleans, false unless explicitly allowed. Each permission
applies only to its own preservation dimension. Do not add preservation, quality,
or recognizability conditions to edits. Do not judge edit success.
